# النمط الخفيف (Serverless) — بلا خادم ولا قاعدة بيانات

فكرة هذا النمط: **لا تخزين إطلاقاً**. المتصفح يجلب بيانات المطر عند الطلب،
والموقع يُستضاف كملفات ثابتة. جهازك مطفأ، لا اشتراكات، لا صيانة.

## المعمارية

```
زائر ──► استضافة ملفات مجانية (Cloudflare Pages / GitHub Pages)
            │
            ├─► نقرة على نقطة ──────► Open-Meteo مباشرة (طلب واحد = كل النوافذ + الارتفاع)
            │                           مجاني، CORS مفتوح، ERA5 منذ 1940، ~10 كم
            │
            └─► تلوين الخريطة ──────► Cloudflare Worker /rain/grid
                                        (يجمع ملفات CHIRPS v3 اليومية العامة،
                                         يخزن مجاميع شهرية في KV — أول مرة ~دقائق،
                                         ثم فوري. نفس عقد /rain/grid المحلي)
```

## لماذا CHIRPS للشبكة وOpen-Meteo للنقاط؟ (درس محسوب)
- **Open-Meteo يحتسب كل إحداثية طلباً** — شبكة المملكة 36,676 إحداثية تتجاوز حصة اليوم (10 آلاف). ممتاز للنقاط (نقرة = طلب واحد)، غير قابل للشبكات.
- **CHIRPS** ملف يومي واحد (~5-15MB) يغطي العالم — تجميع المملكة منه مجاني وبلا حصص، بدقة 0.05° أعلى من ERA5.

## الخطوات

### 1) الواجهة (استضافة ملفات)
```bash
cd apps/web
NEXT_PUBLIC_RAIN_GRID_URL=https://rain-grid.<حسابك>.workers.dev \
NEXT_PUBLIC_TILES_URL=https://<حسابك>.workers.dev/tiles \  # أو أي خادم بلاطات
npm run build && npm run export   # ينتج مجلد out/
```
ارفع `out/` إلى Cloudflare Pages أو GitHub Pages.

### 2) الـ Worker
```bash
cd serverless/rain-grid
npm install
npx wrangler kv namespace create CACHE   # ضع الـ id في wrangler.toml
npx wrangler deploy
```

### 3) التشغيل المحلي (بديل مؤقت للـ Worker)
الـ API المحلي يقدم نفس العقد: `http://localhost:8080/api/v1/rain/grid?from&to`
(أول تجميع ~دقيقة، بعدها كاش يومي 0.08 ثانية).

## ملاحظات صادقة
- **لا حاجة لحساب NASA Earthdata** في هذا النمط — CHIRPS عامة تماماً.
- ترخيص Open-Meteo **غير تجاري**؛ إضافة إعلانات لاحقاً تتطلب بديلاً للنقاط (يمكننا توجيهها لـ CHIRPS نقطياً لاحقاً — نفس البنية).
- دقة ERA5/CHIRPS للعواصف الحادة أقل من IMERG — عند رغبتك بالوضع العلمي الكامل يبقى محرك PostGIS/IMERG جاهزاً (وضع متقدم).
- طبقات الصحراء والأساس والتضاريس ملفات ثابتة (PMTiles/COG) تُرفع مع الموقع أو على أي CDN.

## تحديثات الأداء والدقة (2026-10)
- **تجميع الفترات يستخدم ديكادات CHIRPS** (ملف لكل 10 أيام) للأشهر الكاملة — 3 طلبات بدل 30، مع ارتداد تلقائي لليومي للشهر الحديث وكاش ثلاثي (ديكاد/شهر/يوم).
- **مقياس الألوان متكيف**: يمتد تلقائياً حتى الوسيط 98 لكل فترة (تفاصيل كاملة من 3 أيام حتى 180).
- **ترشيح تدريجي للمجاري** حسب الطول (z6: ≥70كم أو مسمّى ≥35 — 4,400 خط بدل 322,009)، والتفاصيل تتدرج مع التكبير.
- **درس تشغيلي**: أي تعديل على دوال `mvt_*` يتطلب `docker compose restart martin` (تخزين الاتصالات المُعدّة).

## المرحلة 1 — محرك الوسم (2026-10)
- `GET /rain/season?years=N`: مجموع الوسم الحالي (حتى أمس) مقابل متوسط N سنوات — متوسط مم/خلية + نسبة الأراضي ≥5مم + تاريخ سنة-بسنة. كاش 6 ساعات.
- `GET /rain/grid/top?from&to`: أعلى 12 خلية مع أقرب مكان مسماً.
- الواجهة: الوسم افتراضي أول زيارة + شارة «اليوم N/52»، لوحة 📈 للوسم، لوحة 🏆 لأعلى المناطق، رادار 🌧️ (RainViewer)، توقعات 7 أيام في المؤشر والبطاقة.
- `start.sh`: تشغيل بأمر واحد.
